# Python Data Types — From Scratch

A small, runnable, beginner-friendly collection of Python files. Each file focuses on one built-in type and includes examples, comments, and exercises.

## Files

- `boolean.py` — `bool`
- `integer.py` — `int`
- `float.py` — `float`
- `complex.py` — `complex`
- `string.py` — `str`
- `list.py` — `list`
- `tuple.py` — `tuple`
- `set.py` — `set`
- `frozenset.py` — `frozenset`
- `dictionary.py` — `dict`
- `nonetype.py` — `NoneType`
- `bytes.py` — `bytes`
- `bytearray.py` — `bytearray`
- `range.py` — `range`

## How to use

1. Install Python 3 if it is not already installed.
2. Open a terminal in this folder.
3. Run one file, for example: `python boolean.py` (on some systems use `python3 boolean.py`).
4. Read the comments, change the values, and run it again.
5. Solve the exercises at the end of each file. Add your solutions below the prompts.

The examples use only Python's standard library. Lines showing intentional errors are commented out so the files run normally.
